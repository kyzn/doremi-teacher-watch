# Watch teacher icons — v1

Generated with the built-in image_gen tool on 9 September 2026. Style informed by the existing Inutomo and Mapcoder icons inspected locally. These are first design candidates; no app asset catalog has been wired up.

Square artwork is unmasked; the OS applies the icon shape. Original output is preserved in each project as source-v1.png; icon-v1-1024.png is the resized export.

## Morse prompt

Use case: logo-brand. Create a polished standalone Apple Watch app icon for a very simple Morse code learning app, one square image 1024x1024. Full-bleed opaque deep midnight navy background with a very subtle rich blue illumination in the center. Main subject: exactly three large warm golden-yellow softly sculpted solid shapes in a single horizontal row: circular dot, long horizontal rounded capsule dash, circular dot. This is the actual Morse sequence dot dash dot. Dash is roughly three dot diameters long; all three have matching height, evenly spaced, centered as one bold symbol occupying about 70% of width. Beautiful restrained dimensional clay/enamel finish, subtle bevels, soft highlights upper left, gentle shadows, tactile and friendly like a premium illustrated app icon, but extremely simple and legible at watch size. A tiny restrained warm glow is fine; no other symbols. Strong saturated gold against navy, generous negative space, centered composition safe inside a circular crop. Background extends to all square corners; do not draw an outer icon border, tile, rounded square, or circular mask. No text, letters, numbers, telegraph device, watch mockup, interface, watermark, extra dots or dashes. Actual final icon artwork only, not a presentation sheet. Fully opaque RGB artwork.

## Doremi prompt

Use case: logo-brand. Create a polished standalone Apple Watch app icon for a very simple musical note ear-training and humming app called Doremi, one square image 1024x1024. Full-bleed opaque deep midnight navy background with very subtle rich blue central illumination. Main subject: one exceptionally clear, bold conventional beamed pair of eighth notes (two round oval noteheads, two sturdy upward stems joined by ONE gently ascending thick beam), made of luminous mint-to-turquoise softly sculpted enamel/clay. Make the note symbol friendly, substantial and beautifully balanced, subtle dimensional bevels, soft upper-left highlights and gentle shadows, premium tactile illustration without busy decoration. Subject fills about 64% width and 64% height, optically centered, generous negative space, all important shape safely inside a circular watch crop. Strong luminous aqua color against navy, simple silhouette readable at tiny watch icon size. Designed as the companion to a navy icon with three softly sculpted golden Morse dots/dash. Background extends to all square corners; do not draw an outer icon border, tile, rounded square, or circular mask. No text, letters, do re mi words, piano keys, staff lines, microphone, sound waves, extra notes, watch mockup, interface, watermark. Actual final icon artwork only, not a presentation sheet. Fully opaque RGB artwork.
