# App Name

ドレミ先生 ウォッチ

# Subtitle

手首で聴音トレーニング

# Promotional Text

音を聞いて、音名を当てる。音名は標準の高さにも、自分の楽器の調律にも合わせられます。

# Description

Apple Watch で耳を鍛えましょう。

音が鳴ったら、4つの音名から選びます。答える前に何度でも聞き直せます。毎回、正解ともう一度聞くボタンが表示されます。タイマーはありません。

ドレミ表記と ABC 表記を選べます。7つの幹音だけ、または♯・♭を含めて練習できます。

独自の音名で演奏する楽器をお使いですか? 自分の「レ」がどの実音かを設定すると、すべての音名がそれに合わせて変わります。サズ奏者のために作りましたが、移調楽器全般に役立ちます。

練習中は Digital Crown で音量を調整できます。統計では今日と累計の正答率を、全体および音のセットごとに確認できます。

Apple Watch だけで動作。iPhone アプリ不要、アカウント不要、広告なし、トラッキングなし、データ収集なし。
